# CAD Models

A collection of my CAD designs for robotics and mechatronics projects.

![Robot arm preview](images/preview.png)

## Projects
| Project | Software | Formats |
|---------|----------|---------|
| 6-DOF Robot Arm with Gripper | SolidWorks 2022 | SLDPRT, SLDASM, STEP, STL |

## Folder Structure
- `native/` – original CAD files (use Pack and Go so all parts are included)
- `step/` – universal format, opens in any CAD software
- `stl/` – ready for 3D printing
- `images/` – renders and screenshots

## Usage
1. Download the repo with **Code → Download ZIP**.
2. Open the STEP files in any CAD software, or open `native/Assem1.SLDASM` in SolidWorks 2022 or newer.
3. Keep the files in their folders, or the assembly mates will break.
